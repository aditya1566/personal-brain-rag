📋 Session Summary & Project StateProject OverviewRepository: personal-brain-backendStack: Node.js (ESM), Express, TypeScript (NodeNext module resolution), Prisma 7 (@prisma/adapter-pg), Neon PostgreSQL, Bcrypt, JWT (jsonwebtoken), tsx.Key Decisions & Implemented ArchitectureAuthentication Flow:User Registration (POST /api/auth/register): Hashes passwords using bcrypt (10 salt rounds), creates User records in Neon PostgreSQL, and strips passwordHash from the response.User Login (POST /api/auth/login): Validates credentials and returns a signed stateless JWT token (expiresIn: '7d').Middleware (authenticateToken): Validates Bearer <token> headers from Authorization headers, decodes the user payload, and attaches userId and email to req.user.TypeScript & Module Configuration:ES Module Imports: Relative imports retain .js extensions (e.g., import prisma from '../config/db.js') to comply with Node.js ESM/NodeNext module resolution.Express Type Augmentation: Created src/types/express/index.d.ts extending Express.Request with user?: { userId: string; email: string; }.Environment Variables: Used import 'dotenv/config' across config and middleware files to guarantee .env variables load prior to runtime module evaluation.Database Setup (src/config/db.ts):Configured Prisma 7 with the @prisma/adapter-pg driver adapter for Neon PostgreSQL over SSL (?sslmode=require).Configured a global singleton instance for PrismaClient to avoid connection exhaustion in dev mode.Project Directory MapPlaintextpersonal-brain-backend/
